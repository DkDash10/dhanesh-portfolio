# Dhanesh Portfolio

A bold, interactive personal portfolio built with React and Vite, crafted to showcase frontend work, case studies, creative direction, and contact information in a cinematic single-page format.

## About

This portfolio belongs to Dhanesh Kumar Dash and reflects a design-first approach to front-end development. The experience combines strong typography, layered motion, custom UI interactions, and a responsive layout to create a memorable overview of the creator's work, interests, and capabilities.

## Highlights

- Rich hero section with layered background motion and video treatment
- About section with editorial storytelling and interest-based cards
- Project case studies with motion-first video showcases
- Motion Lab section for visual experimentation and creative exploration
- Toolkit section highlighting technologies and strengths
- Contact section with email, LinkedIn, GitHub, and resume access
- Smooth scroll, GSAP animation, custom cursor, and theme toggling

## Tech Stack

- React 19
- Vite
- JavaScript (JSX)
- Tailwind CSS
- GSAP
- Lenis
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18 or newer
- npm

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Available Scripts

```bash
npm run dev      # start the Vite dev server
npm run build    # create a production build
npm run preview  # preview the build locally
npm run lint     # run ESLint checks
```
